# 信息载体路由

每个语义段只能选择一个主路线：

- `KEEP_A_ROLL`：真人表情、个人经历、主观判断、免责声明、直接提问、情绪转折。
- `REAL_EVIDENCE`：论文、文章、官方文档、产品截图、真实数据来源、引用、Logo、历史照片。缺失时阻塞审批，不得降级为生成图。
- `EXISTING_MEDIA`：用户已有的产品照片、现场照片、实拍截图或授权图片。P0 只接受静态图片。
- `DETERMINISTIC_GRAPHIC`：文字、精确数字、流程、因果、左右对比、时间线和分类关系。
- `GENERATED_IMAGE`：场景、物体、空间、人物化概念、抽象隐喻或氛围，默认无可读文字。

决策顺序：先判断真人是否不可替代，再判断真实性是否是核心，然后检查已有素材，再考虑确定性图形，最后才使用生成图。

真实性红线：不生成伪论文、伪报道、伪产品界面、伪数据图、伪 Logo；不让 ChatGPT 生图承担需要逐字准确的中文；可能被误认为纪实证据的镜头必须标记 `aigc_disclosure_required: true`。
