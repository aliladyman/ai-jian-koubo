# 口误检测规则

## 输入输出

输入：编号句子列表（`序号: 文本`）
输出：JSON `{delete_sentences: [...], delete_idx: [...]}`
- `delete_sentences`：要整句删除的句号数组，如 `[2, 3, 11]`
- `delete_idx`：要词级删除的 idx 数组（需先调用 `gen_word_detail.js` 查词级 idx）

## 剪辑目标

剪出**可直接发布**的视频稿。在保证语义完整的前提下，尽量删除一切不必要的口癖、过渡词、填充词，让句子流畅紧凑。**判成无功能的口癖直接删，不逐个犹豫；承担语义/语气的词拿不准就留**（误删比漏删难恢复，与 SKILL.md 5.5 "漏删优于过删"同口径）。

## 重要前提：输入是语音转录

你看到的文本是 ASR 语音转录，**会有同音错词、专有名词识别错误**（例如 `OPC点` 实际是 `Obsidian`、`卡巴西/卡帕西` 实际是 `Karpathy`、`Hans/哈尼斯` 实际是 `Harness`）。

- **不要纠正**这些识别错误，文字层面的纠正不是你的任务
- **不要因为看到错字就把句子当口误删掉** —— 错字只是转录问题，原话本身是流畅的
- 你只判断"原话有没有口误"（重复、残句、卡顿、口癖），不要判断"转录文字是否正确"

## 核心原则

**删前保后（默认，不机械）**：同义重说时，后说的通常更完整 → 默认删前面、留后面。但要按 A1 的 retake 四步验证：后一版缺主语/结论，或前一版有后一版没有的必要铺垫时 → 保更完整的那一版、或把前一版独有的铺垫留下来接到保留版上。

## A. 整句删除规则

### A1. 重复 / 重说（retake 四步）

判定流程（来源：ChatCut 方法蒸馏 2026-07，取代旧"一律留最后一句"）：
1. **先判是不是 retake**：多次尝试说同一个意思才算；刻意强调、修辞重复、补充了新信息的第二遍不算，不删
   - 高危误判形态——**陈述句复述成反问/设问**（「它替我回答。问题来了，它怎么能替我回答呢？」）：两句字面高度相似，但后句是疑问句式、作用是引出下文而非重说前句 → 是修辞不是 retake，两句都保留（2026-07-24，源自 xiaolan-aroll 实测误报案例）
2. **定义要保留的完整版本**：完整版不止主句——引入、连接词、对比、限定语被保留内容依赖时，都算保留范围
3. **只删失败/被覆盖的部分**：前面尝试里有后面没重复的有用铺垫 → 保下来接到完整版上。5.3 句级判断的执行口径：含独有铺垫的句子**整句保留**（不进 delete_sentences），句内失败部分留给 5.5 词级处理——此操作属下方禁令的豁免范围
4. **选最优完整版本**：通常偏后面那次，但不机械选最后一次——后一版缺主语/结论时，保更完整的那一版

识别信号（命中即进上面流程）：
- 相邻句开头 ≥5 字相同
- **短句护栏（负向门槛，2026-07-24）**：整句去标点后不足 8 字的（「对吧」「是吧」「所以呢」这类），不因与邻句相似就判重复——短句相似度天然虚高，只有连同上下文构成完整同义重说时才按 A1 处理
- 3 句及以上连续同义重说 → 只留最完整的那一句
- 完整句 + 残句 + 完整句，前后内容相近 → 通常删前两句（先按第 3 步查铺垫）
- 句子被后文完整版覆盖 / 是前文的部分重复 / 词被打断后重说 → 通常整句删（仍先过第 2/3 步查铺垫；否定纠正时删的是**被纠正的前句**，不是纠正句）

**禁令**：不许把不同尝试里的半截句子拼成一句人没说过的话（同一意图内"铺垫 + 纠正"的句内拼接除外，见 B4）。

### A2. 残句
话说一半、不完整、明显烂尾 → 整句删

### A3. 句内卡顿
- 同词连说 2-3 次（A+A 或 A+1-3字+A）→ 整句删
- 例外（不删）：列举、英文词组、固定搭配（"一个一个地"等）

### A4. 仅含语气词 / 口癖的整句
整句仅由以下成分组成 → 整句删
- 语气词：嗯、啊、哎、诶、呃、额、唉、哦、噢、呀、欸
- 应答口癖：对、好、好吧
- 两个语气词紧挨且无实质内容

## B. 局部删除规则（词级）

> **本节由 `scripts/auto_filler.js` 自动处理，AI 不需要手填 `delete_idx`**。
> 脚本覆盖：单字语气词、句首过渡词（然后/那么/好的/那/对/呢/哎/啊/哦/呀）、
> 任意位置的"然后"、句尾废词（对/呢/啊/哦）。
> 仅当遇到脚本未覆盖的情况（如 B3 冗余引导短语），再手动调 `gen_word_detail.js` 追加 idx。

句子主体有效，但局部有口癖 → **不删整句，只删局部词**。

### B1. 句首过渡词
句首出现以下词、且后续是完整意群 → 删句首词
- 名单：然后、那么、好、好吧、哦、对、呢、哎、那

### B2. 句中填充词
中间穿插的口癖 → 只删填充词，保留主体
- 名单：然后（非承接）、对、呢、其实、就、也、大概、哦、呃、那个、这个、就是
- 覆盖注：呃（任意位置）、哦（句首句尾）已被脚本删；"然后"脚本全删，"非承接"限定只在复核加回时用（按 C 节示例）；其余词属语境依赖词，AI 追加时过 C 节四判据

### B3. 冗余引导短语
- 名单：大家可以看到、你看、给大家看一下、比如说你看一下、我可以告诉你、你明白吗

### B4. 句中重说
前半段说错、后半段纠正 → 删前半段，保留后半段
- 前半段里有后半段没有的必要铺垫（时间/条件/对象）→ 铺垫保留，只删说错的部分
- 仅限**同一意图**的句内纠正；跨意图的两个半截句不许拼成一句（见 A1 禁令）

### B5. 句尾废词 / 拖音
句尾出现"对""呢""哦""啊"等无功能词 → 删尾词

## C. 语境词判定（四判据）

两级分治（来源：ChatCut 方法蒸馏 2026-07）：
- **纯迟疑音**（呃 / 额 / 诶 / 欸 / 唉 / 噢 等单字语气词）→ 无语境含义，机械删。脚本覆盖边界：呃/嗯/额/诶/欸/唉/噢 任意位置已删；啊/哦/哎/呀 只删句首句尾——**句中出现时由 5.5 追加**，仍按纯迟疑音口径机械删，不必过四判据
- **语境依赖词**（然后 / 就是 / 那个 / 那 / 对 / 所以 / 但是 / 其实 / 就 等）→ 不按词表一刀切，逐个过四判据：
  1. 只是垫话、无功能 → 删
  2. 承担顺序 / 转折 / 因果 / 指代 / 回应 / 强调 / 语气 → 留
  3. 删了会让前后音硬拼、听感突兀 → 留（或只在审核页压停顿）
  4. 拿不准 → 留（漏删优于过删）

适用范围：① AI 在 5.5 手动追加词级删除时必须过四判据；② 审核网页上复核脚本机械勾选的语境词，按四判据决定是否取消勾选。**B 节脚本的机械行为不变**——"然后"等机械预删是用户拍板的偏好（宁可审核时手动加回），四判据不推翻它，只管 AI 的追加判断和人工复核口径。

"然后"示例（频次最高）：
- **删**：句首单纯起头、句中两段并列时的口癖式连接、连续多个"然后"
- **保留**：真正表达"先 A 后 B"的时序（如"然后我们再看第二点"的顺序标记），或"做了 X 然后才 Y"的因果

## D. 停顿处理（口径参考）

停顿不是 AI 的删除对象——输出 schema 只有 `delete_sentences` / `delete_idx`，没有停顿通道；停顿由脚本与审核网页处理。本节是人工调参和判断的口径（来源：ChatCut 方法蒸馏 2026-07）：

### D1. 先分类再压缩（2026-08-17 用户确认）

| 类别 | 判据 | 动作 | 人审等级 |
|---|---|---|---|
| natural-boundary | 句法完整、语气需要换气 | 保留 0.3–0.5s | auto-safe |
| thinking-hesitation | 同一句内找词，但删除后语义/情绪不变 | 只压缩超长部分，至少留约 0.3s | review-required |
| retake-boundary | 失败版本结束到完整重录开始 | 随失败版本删除，保留完整版起音保护 | auto-safe 或 review-required |
| abnormal-silence | 非表达需要的长静音 | 压到约 0.3s，不清零 | review-required |

禁止规则：不得因为 gap 长就直接删除；不得用 `ka/cut` 口令作为生产前提；不得通过均匀阈值
覆盖语义分类；不得把人工批准写回算法 confidence。

- 停顿**压缩不清零**：>0.8-1s 的长停顿压到 ~0.3s；句与句之间保 0.3-0.5s（听得出自然断句）
- 话题转换 / 对比 / 强调处允许留更长，不剪得赶；句内正常呼吸不动
- 不无中生有：加长停顿只能恢复原始录音里真实存在过的静音
- 用户给了明确阈值 → 完全按用户的

> ⚠️ 当前脚本默认比此口径激进：`scripts/lib/compute_keeps.js` 把保留段内 ≥0.2s 的静音全部二次切掉（minInternalSilence=0.2；内部静音切割只留 ≈0.07s 句尾余量 padEnd=2 帧，删除段边界另留 ≈0.13s）。要让成片贴近本节口径，需调脚本参数或审核页留白设置——属行为改动，改默认值前先和用户确认。

## 词汇参考

> 新旧术语映射：本表"语气词"≈ C 节**纯迟疑音**；"过渡词 / 填充词 / 应答口癖（对、好、好吧）"≈ C 节**语境依赖词**（含表外的"所以 / 但是"）——AI 追加删除时一律以 C 节四判据为准。

- **语气词**：嗯、啊、哎、诶、呃、额、唉、哦、噢、呀、欸
- **应答口癖**：对、好、好吧
- **过渡词**：然后、那么、那
- **填充词**：其实、就、也、大概、那个、这个、就是、呢
- **冗余短语**：大家可以看到、你看、给大家看一下、我可以告诉你、你明白吗
- **典型卡顿**：那个那个、就是就是、然后然后、这个这个、所以所以
